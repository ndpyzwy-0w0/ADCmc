# ADCmc

[English](README.md) | [中文](README.zh-CN.md)

可控的 Windows 连点器：左右键双通道、速度曲线、随机时间偏移、热键/双击触发、DPI 自适应界面、本地设置记忆。**仅供学习研究使用。**

## 功能

| 功能 | 说明 |
| --- | --- |
| 左右键板块 | 左右键独立连点板块，并排显示 |
| 速度曲线 | 恒定 / 加速 / 减速 / 正弦 / 缓入缓出 / 自定义 |
| 随机偏移 | 可开关的随机时间偏移 |
| 绑定键触发 | 录制键盘或鼠标侧键，按住连点 |
| 双击触发 | 双击间隔小于阈值开始；阈值内无继续输入则停止 |
| DPI 自适应 | 适配高分屏与系统缩放，窗口可调整大小并滚动 |
| 设置文件 | 同目录 `ADCmc_settings.txt` 记住设置 |

## 环境

- Windows 10/11
- Python 3.12+（源码运行）
- 依赖见 `requirements.txt`（`pynput`；打包用 `pyinstaller`）

## 源码运行

```powershell
cd ADCmc
python -m pip install -r requirements.txt
python main.py
```

## 打包 exe

```powershell
.\build.ps1
```

生成文件：`dist\ADCmc.exe`

## 说明

- 关闭软件时会保存设置到可执行文件/脚本同目录。
- 若删除 `ADCmc_settings.txt`，下次启动恢复默认并重新生成。
